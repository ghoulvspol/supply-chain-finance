# 供应链金融知识图谱

> 作者：滔哥与Claude Code

从概念到实践，构建供应链金融的完整认知体系。

## 知识图谱内容

| 维度 | 数量 | 说明 |
|------|------|------|
| 核心概念 | 20 张 | 应收账款融资、反向保理、存货融资等 |
| 参与主体 | 12 张 | 核心企业、银行、保理公司、科技平台等 |
| 业务模式 | 10 张 | 保理、反向保理、存货质押、ABS 等 |
| 风控体系 | 8 张 | 信用风险、操作风险、贸易真实性验证等 |
| 政策法规 | 6 张 | 供应链金融指导意见、民法典保理合同章等 |
| 典型案例 | 8 张 | 汽车、医药、电子、农业等行业实践 |
| **合计** | **64 张** | |

## 知识图谱结构

```
供应链金融（信用锚点：核心企业）
├── 核心概念 (20)
│   ├── 融资工具：应收账款融资、反向保理、保理、存货融资...
│   ├── 金融产品：供应链金融ABS、电子债权凭证、资产证券化
│   ├── 风险与信用：信用风险、操作风险、贸易真实性、核心企业信用
│   └── 技术创新：金融科技
├── 参与主体 (12)
│   ├── 资产端：核心企业、上游供应商、下游经销商
│   ├── 资金端：商业银行、保理公司、投资机构
│   ├── 服务端：金融科技平台、物流企业、担保机构、保险公司
│   └── 监管端：监管机构
├── 业务模式 (10)
│   ├── 基于应收账款：应收账款保理、反向保理
│   ├── 基于存货/预付：存货质押、预付款融资
│   ├── 基于订单/票据：订单融资、票据池融资
│   ├── 创新模式：电子债权凭证流转、供应链ABS、平台化
│   └── 跨境场景：跨境供应链金融
├── 风控体系 (8)
├── 政策法规 (6)
└── 典型案例 (8)
```

## 技术栈

- **知识管理**：Obsidian Vault（Markdown + Wikilinks）
- **网站构建**：Python 脚本（Markdown → HTML）
- **设计风格**：Notion 暖米色 + 海军蓝侧栏 + 金色强调
- **部署**：Caddy + HTTPS

## 本地运行

```bash
# 构建网站
python3 build_site.py

# 打开首页
open site/index.html
```

## 部署

参见 `templates/caddy-block.txt` 配置 Caddy 反向代理。
