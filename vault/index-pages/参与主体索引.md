# 参与主体索引

<p style="color:var(--text2);font-size:14px;margin-top:-8px;margin-bottom:32px">供应链金融生态中的关键角色，从资金端到资产端，每个主体都有独特的价值定位。</p>

## 资产端

| 主体 | 角色定位 |
|------|---------|
| [[核心企业]] | 供应链主导企业，信用源头 |
| [[上游供应商]] | 提供原材料/零部件的中小企业 |
| [[下游经销商]] | 产品的分销渠道 |

## 资金端

| 主体 | 角色定位 |
|------|---------|
| [[商业银行]] | 主要资金提供方 |
| [[保理公司]] | 专业应收账款服务商 |
| [[投资机构]] | ABS 等产品的资金方 |

## 服务端

| 主体 | 角色定位 |
|------|---------|
| [[金融科技平台]] | 技术赋能方，搭建数字化平台 |
| [[物流企业]] | 仓储监管、运输监控 |
| [[担保机构]] | 提供信用增级 |
| [[保险公司]] | 提供贸易信用保险 |
| [[供应链管理公司]] | 供应链整合服务 |

## 监管端

| 主体 | 角色定位 |
|------|---------|
| [[监管机构]] | 银保监会、央行等 |
